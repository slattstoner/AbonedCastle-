# Abandoned Castle — карта проекта

Читай этот файл первым. Он короткий: что это за проект, как работать и **в какой файл идти за чем**. Остальное открывай только по надобности.

## 1. Что это

Аддон для **Minecraft Bedrock 1.26.x** на **iPhone**: заброшенный замок «Студёный детинец», который оживает. Игрок ставит замок грамотой, чинит его руками работников, помогает жителям, раскрывает тайну. Всё делается кодом: постройки описаны в JS, сборщик генерирует аддон.

**Версия 0.11.0**, ветка `claude/beautiful-archimedes-q8lknv`. В игре не проверены 0.10.0–0.11.0.

## 2. Пользователь и правила работы

- Не разработчик, **ПК нет, только iPhone**. Пиши по-русски, простыми словами. В конце работы — короткий отчёт: что сделано, что проверено, что осталось.
- Тестирует сам в игре, присылает скриншоты. Готовый аддон отправляй файлом: `dist/AbandonedCastle_Taiga.mcaddon` (`SendUserFile`, `display: attach`). Напоминай удалить старую копию.
- После каждого изменения в аддоне **поднимай версию** (`PACK.version` в `tools/build.js`).
- Порядок: сначала согласовать, потом код. Если пишет «начинай» или «поработай» — делай. Не ответил на вопрос — выбери разумно сам и скажи, что выбрал.
- Ценит: проработанные истории и тайники, средневековую обстановку, светлые комнаты, **настоящую** работу жителей (не имитацию).
- Рендеры и 3D-превью — только если попросит.
- **Перед работой сверь версию с пользователем и посмотри все ветки** (`git fetch origin && git branch -r`): однажды два чата вели разные линии, пришлось сращивать.
- Коммить по-русски и пуши в ветку сессии. Ветку `claude/minecraft-mod-story-gameplay-7y5cro` не использовать (пользователь решил удалить).

## 3. Сборка и проверка (перед каждой отправкой)

```
node tools/build.js        # аддон → dist/, проверки блоков, света, проходов, мест жителей
node tools/test/sim.mjs    # прогон скриптов на макете мира → «всё сработало»
```

- **Предупреждений сборщика быть не должно.** Всё новое дописывай в прогон.
- В макете прогона нет блоков самого замка: работу зодчего на донжоне и ходьбу по комнатам он не проверяет.
- Скрипты можно сверить с описаниями API Mojang: `npm i typescript @minecraft/server@2.4.0 @minecraft/server-ui@2.0.0` во временной папке и `tsc --allowJs --checkJs` по `build/AbandonedCastle_BP/scripts`.
- Трогал `builder.js` или `bedrock.js` — сравни md5 шаблонов тайги до и после.

## 5. Что нельзя забывать (подводные камни)

- Оси: x — восток, z — юг; **y = −1 — верхний слой земли**, постройка стоит с y = 0. У лестниц, рамок, знамён, настенных факелов `f` — **сторона стены**.
- Замок ставится 36 кусками 32×32; после них идёт **второй проход** (`castle_fix_N`) для всего, что крепится к стенам. Замок 188×192, уходит на 25 блоков вниз — в плоском мире ставить нельзя.
- У существ, которых водит скрипт, не должно быть своего «дома» (`minecraft:home`): игра тянет к месту появления, существо топчется.
- Проверяй, **где стоит само существо**, а не только состояние в памяти.
- Память мира — до ~32 КБ на ключ: у модулей свои ключи (`acastle:state`, `acastle:work`, `acastle:garrison`, `acastle:gate`).
- В пулах генерации `location` — путём к файлу (`acastle/taiga/...`), не через двоеточие. `"projection": "minecraft:rigid"` не писать.
- В записках и подсказках **нет сторон света** (игра поворачивает постройки): только приметы.
- Предметы для заданий — только то, что есть в тайге и в шахте (без пчёл, арбузов, тростника).
- На iPhone одновременно живёт около 60 существ аддона — это близко к пределу; прибавлять осторожно.

## 6. Команды для проверки в игре

| Команда | Что делает |
|---|---|
| Королевская грамота (предмет) или `/function castle` | поставить замок |
| `/scriptevent acastle:status` | версия, где замок, задания, кто на месте |
| `/scriptevent acastle:reset` | забыть замок и вернуть грамоту |
| `/scriptevent acastle:test_done <задание>` | засчитать задание |
| `/scriptevent acastle:work help` | работники (`status`, `fill`, `orders`, `order <id>`, `finish <id>`, `tp`, `reset`…) |
| `/scriptevent acastle:guard status` | гарнизон (`all`, `dismiss <id>`, `day`, `night`, `tp <id>`) |
| `/scriptevent acastle:gate open` / `close` | решётка ворот |

## 7. Где остановились

Отправлена 0.11.0, ждём проверки в игре. Спросить: не тормозит ли iPhone; ходят ли жители к рабочим местам; работает ли пахарь; приходят ли ночные разбойники; как Мирон чинит донжон; видна ли новая броня; не падают ли факелы после стройки.

Дальше (пользователь выберет порядок):
1. **Интерьер вручную** — донжон, казарма, остальные здания; применение пустым комнатам.
2. **Новая основная линия** — тайна королевы, Рыжий, Ножов, осада, наследие (материал — в `stages.js`, план — `docs/STORY.md` §7).

4. Отложено пользователем: торговля, награды хозяину замка, модель белого лося, естественная генерация замка, другие биомы.

# Abandoned Castle — аддон для Minecraft Bedrock

Заброшенный замок «Студёный детинец», который оживает: жители, работники, стража, задания, тайные комнаты. Для Minecraft Bedrock 1.26.x (проверяется на iPhone). Версия 0.11.0.

## Установка

1. Удалите старую копию аддона из игры (иначе останется прежняя версия).
2. Откройте `dist/AbandonedCastle_Taiga.mcaddon` — игра установит два пакета: поведение и внешность.
3. Создайте **обычный** мир (не плоский) и включите в нём оба пакета. Экспериментальные настройки не нужны.

## Как начать

1. При входе в мир в сумке появится **Королевская грамота**.
2. Найдите ровное открытое место вдали от своего дома и примените грамоту (долгое нажатие). Замок строится около минуты; вы окажетесь на площади у ворот.
3. Подойдите к воротам и коснитесь стражника Остапа — он заговорит и даст книгу заданий.

Говорить с жителями: коснуться жителя или нажать кнопку «Говорить». Книга заданий показывает подсказки и ведёт к цели.

## Команды для проверки (нужны читы)

| Команда | Что делает |
|---|---|
| `/scriptevent acastle:status` | версия, где замок, задания, кто на месте |
| `/scriptevent acastle:reset` | забыть замок и вернуть грамоту |
| `/scriptevent acastle:work help` | работники: шахтёр, зодчий, кузня |
| `/scriptevent acastle:guard status` | гарнизон |
| `/function castle` | поставить замок командой (запасной путь) |

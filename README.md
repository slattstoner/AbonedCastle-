# Abandoned Castle — мод для Minecraft Bedrock

Замок из замшелого камня в упадке, который игрок восстанавливает вместе с работниками и стражей. Вокруг — тайга с постройками, тайниками и историями.

Готовый аддон: [`dist/AbandonedCastle_Taiga.mcaddon`](dist/AbandonedCastle_Taiga.mcaddon) — **версия 0.9.5**.
Для разработки (и нового чата с ИИ) — начинать с [`CLAUDE.md`](CLAUDE.md). Указатель по документам — [`docs/README.md`](docs/README.md).

## Что в аддоне

- **Замок** 140×144 блоков: донжон в пять этажей, библиотека, катакомбы, часовня со склепом, двор с казармой, кузницей, конюшней, амбаром. Встаёт в упадке: стены почти снесены катапультами, в донжоне темно и разруха.
- **Работники** делают настоящую работу:
  - рудокоп **Кондрат** копает шахту у кузни: ствол лесенкой вниз, три горизонта (уголь, железо, алмазы), на каждом двор, коридоры и ветки; добычу кладёт в сундуки у копра;
  - подмастерье **Васька** носит руду в кузню, камень — на склад строителя, кирки и рельсы — к копру;
  - кузнец **Гордей** плавит руду и куёт броню страже по званию, мечи новобранцам, кирки, рельсы; что он куёт, видно в рамке на верстаке;
  - зодчий **Мирон** по книге работ чинит стены блок за блоком: сначала частокол, потом камень, потом башни.
- **Гарнизон** из 23 стражников: две смены (у каждого своя койка в казарме), пересменка, обходы двора раз в несколько минут, дозорные в башнях, лучники, гридни у покоев короля; на ночь решётка ворот опущена, ночной караул в надвратных башнях; набор через капитана.
- **Опускная решётка** в главных воротах на рычагах.
- **Сюжет** из 10 этапов (тайна пропавшего княжича) — в скриптах, сейчас отложен.
- **Тайга:** 17 построек и 30 историй; сейчас появляются только по заданиям сюжета.

## Установка на iPhone

1. Удали старую копию аддона из настроек мира и из хранилища Minecraft, иначе игра оставит старую.
2. Открой `AbandonedCastle_Taiga.mcaddon` из «Файлов» или из чата — Minecraft импортирует оба пакета (поведение и внешность).
3. Мир **обычный** (не плоский: замок уходит на 25 блоков вниз), с читами. В настройках мира включи оба пакета «Abandoned Castle». Экспериментальные функции не нужны.
4. Встань там, где должна быть площадь у ворот, и введи `/function castle`. Замок строится около минуты, ход видно внизу экрана.

## Как начать

- Кондрат стоит у копра рядом с кузницей. Положи в бочку у копра кирку и факелы (или уголь), коснись его → «Начинай копать».
- Мирон — на дворе строителя у ворот. Положи на склад камень и брёвна, коснись его → выбери работу → «Берись».
- Гордей — в кузне. Железо и уголь — в сундук кузни у стены. Коснись его → выбери, что ковать.
- Капитан Демьян (приходит по сюжету) → «Гарнизон» → набрать стражника (меч скуёт Гордей).

## Команды для проверки

| Команда | Что делает |
|---|---|
| `/scriptevent acastle:status` | что знают скрипты |
| `/scriptevent acastle:work status` | что делают работники, ошибки |
| `/scriptevent acastle:work fast 10` | работники в 10 раз быстрее (`fast 1` — обычно) |
| `/scriptevent acastle:work label` | подписи над головой работников |
| `/scriptevent acastle:work fill` | материалы для проверки в сундуки и бочку |
| `/scriptevent acastle:work ledger` | счёт: всё добытое учтено |
| `/scriptevent acastle:guard status` | где стражники, что на них |
| `/scriptevent acastle:guard all` | набрать весь гарнизон сразу |
| `/scriptevent acastle:guard night` / `day` | ночь или день (посмотреть пересменку) |
| `/scriptevent acastle:gate close` / `open` | решётка ворот |
| `/scriptevent acastle:jump N` | сюжет сразу к этапу N |

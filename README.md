# Abandoned Castle — мод для Minecraft Bedrock

Мод добавляет в мир генерируемые постройки с тайниками и историями. Первый биом — тайга.

## Структура

- `design/preview/` — 3D-эскизы построек. Открой `index.html` в браузере.
  - `blocks.js` — справочник блоков (идентификаторы Bedrock).
  - `builder.js` — конструктор построек.
  - `structures/*.js` — сами постройки и метки тайников (`slot`), подсказок (`clue`) и секретов (`secret`).

Эти же описания построек потом будут собираться в `.mcstructure` для аддона.
